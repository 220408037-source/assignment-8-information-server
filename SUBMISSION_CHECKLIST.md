# Submission checklist

- [ ] `package.json` declares `type: module` and Express 5.
- [ ] `package-lock.json` is included.
- [ ] `node_modules/` and `.env` are not committed.
- [ ] `npm install` completes successfully on the submission machine.
- [ ] `npm start` starts the server and prints its URL.
- [ ] The browser page works at `http://localhost:3000`.
- [ ] All routes and both 404 response types have been tested.
- [ ] README contains actual curl output, not only expected output.
- [ ] README reasoning and self-study answers have been reviewed and personalized.
- [ ] GitHub repository contains at least 10 meaningful commits with visible progress.
